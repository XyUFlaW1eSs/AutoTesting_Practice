# 手工测试课程目录

所有保险业务均为虚构练习案例。每课应留下可评审产物，而不只是阅读笔记。

1. [测试基础与流程](01-测试基础与流程.md)：测试原则、生命周期、类型、角色与策略。
2. [需求分析与用例设计](02-需求分析与用例设计.md)：测试点、等价类、边界值、判定表、状态迁移。
3. [缺陷管理与回归测试](03-缺陷管理与回归测试.md)：缺陷报告、严重程度/优先级、复测与回归。
4. [Web、接口与 SQL 测试](04-Web接口与SQL测试.md)：Network、HTTP、API、SQL、数据一致性。
5. [UAT 全流程验收测试](05-UAT全流程验收测试.md)：验收计划、场景、数据、问题、报告。
6. [大型项目完整缺陷报告与测试交付示例](06-大型项目完整缺陷报告与测试交付示例.md)：完整缺陷报告、日报、测试总结、UAT 记录和关闭条件。
7. [测试设计技术与需求追踪实战](07-测试设计技术与需求追踪实战.md)：等价类、边界值、决策表、状态迁移、追踪矩阵和用例质量评审。

## 推荐练习链路
投保申请 → 核保 → 模拟支付 → 保单生成 → 保单查询。重点验证合法与非法状态转换、重复请求、支付失败、对象级授权以及 UI/API/DB 一致性。

## 需要掌握的项目交付能力
- 测试计划：范围、目标、策略、资源、环境、风险、进度、进入/退出条件。
- 测试用例：前置条件、数据、步骤、预期、优先级、需求关联。
- 缺陷报告：环境、版本、步骤、预期/实际、证据、影响、严重程度、优先级。
- 测试执行日报：计划/执行/通过/失败/阻塞/未执行和风险。
- 测试总结：统计口径、未解决缺陷、覆盖盲区、发布风险和建议。
- UAT：业务场景、验收标准、业务签署和风险接受记录。

## 缺陷报告的基本标准
开发人员只看报告即可建立相同前置状态并复现；预期结果能追溯到已确认需求；实际结果是客观事实而不是根因猜测；证据已脱敏；复测和关闭条件明确。
