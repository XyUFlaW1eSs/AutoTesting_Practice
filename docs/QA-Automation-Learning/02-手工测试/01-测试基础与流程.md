# 第 1 课：测试基础与流程

## 目标
解释测试目标与局限；区分开发生命周期和测试生命周期；区分功能、冒烟、回归、系统、验收和非功能测试。

## 核心知识
测试用于发现缺陷并提供质量风险信息，不能证明软件绝对没有缺陷。典型测试生命周期：需求分析 → 测试计划 → 用例设计 → 环境/数据准备 → 执行 → 缺陷跟踪 → 复测/回归 → 测试总结。
- 功能测试：检查系统行为是否符合需求。
- 冒烟测试：快速判断构建版本的核心功能是否可测。
- 回归测试：确认变更没有破坏已有能力。
- UAT：业务用户/授权代表依据业务验收标准确认系统是否满足业务需要。
- 非功能测试：性能、兼容性、可用性、安全性等。

## 示例：保单查询
需求：登录用户可查询自己有权限访问的保单。
1. 澄清保单号格式、无结果表现、权限和服务异常行为。
2. 准备两个用户及各自保单。
3. 测试有效保单、无效编号、空值、他人保单、无结果和接口异常。
4. 记录输入、步骤、预期、实际与证据。
5. 修复权限缺陷后复测，并回归普通查询。
6. 总结覆盖范围、结果、阻塞项与剩余风险。

## 练习
- 为“登录后查看保单”写测试流程。
- 写 3 条冒烟和 5 条回归用例并解释选择理由。
- 说明为什么所有用例通过仍不代表零风险。

## 验收标准
能用 3 分钟讲清测试流程；能区分功能、回归与 UAT；能结合范围和风险说明测试结论。
