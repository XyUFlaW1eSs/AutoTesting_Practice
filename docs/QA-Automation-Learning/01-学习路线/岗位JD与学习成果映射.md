# 岗位 JD 与学习成果映射

| JD 要求 | 学习模块 | 面试可展示成果 |
|---|---|---|
| 功能/手工测试 | 测试流程、需求分析、用例、缺陷、回归 | 测试计划、30–50 条用例、缺陷单、回归记录 |
| UAT 全流程 | UAT 课程与综合项目 | 验收计划、端到端场景、验收报告、风险清单 |
| 自动化测试 | Python、pytest、requests、Selenium、Playwright | 可运行代码、测试报告、失败定位记录 |
| 保险经验加分 | 虚构投保业务练习 | 能讲清投保、核保、模拟支付、保单状态 |
| 英语加分 | 官方技术文档 | 能读懂常见 API、错误和框架文档 |

## 面试要向招聘方确认
1. 手工测试、UAT、自动化在实际项目中的工作比例？
2. 自动化组使用哪些语言和框架？推荐/转组条件是什么？
3. 是否会实际编写和维护脚本，还是主要执行已有脚本？
4. 项目周期、客户现场要求和项目结束后的安排？
5. 合同主体、加班制度、社保公积金缴纳基数等具体条件？

所有保险场景是个人练习，不应描述为真实企业项目或客户经验。
