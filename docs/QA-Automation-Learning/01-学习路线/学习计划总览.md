# 学习计划总览：手工测试 + 自动化测试

## 目标岗位映射
JD 明确提到功能测试、手工测试、自动化、UAT 全流程验收测试。优先级：P0 手工功能测试与 UAT；P1 SQL/接口与 pytest 自动化；P2 Selenium、Playwright、Git/CI；保险业务与英语为加分准备。目标公司的实际技术栈需面试确认。

## 六周安排（每天 2–3 小时）
| 周 | 主题 | 重点产出 |
|---|---|---|
| 1 | 测试流程、需求分析、用例、缺陷、Web | 30 条用例、5 个模拟缺陷 |
| 2 | HTTP、API、SQL、回归与风险 | API 用例、SQL 检查、测试总结 |
| 3 | 保险业务、UAT 全流程 | UAT 计划、10–15 个场景、验收报告 |
| 4 | Python、pytest、fixture | 可运行测试项目 |
| 5 | requests、Selenium、Playwright | API/UI 自动化脚本 |
| 6 | 框架、日志报告、Git、CI/CD | 综合作品集和 CI 运行记录 |

## 每日节奏
20–30 分钟学习概念；45–60 分钟跟做；45–60 分钟独立练习；15 分钟记录错误和复习问题。若每天只有 1 小时，延长至 10–12 周。
