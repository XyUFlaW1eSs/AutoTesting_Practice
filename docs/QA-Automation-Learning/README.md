# 软件测试与自动化测试系统学习资料

面向功能测试、手工测试、自动化测试与 UAT 全流程验收测试岗位。所有保险业务均为虚构练习规则，不代表真实保险产品或真实企业项目。

1. [学习路线总览](01-学习路线/学习计划总览.md)

## 每课学习方法
读概念 → 跟做示例 → 独立完成练习 → 对照验收标准 → 记录问题与复习日期。建议每天 2–3 小时，六周完成第一轮。

## 环境
Windows 11、Git、Python 3.11+、VS Code/PyCharm。使用虚拟环境；密钥、Token、真实个人数据不得提交到仓库。Selenium 需要浏览器，Playwright 安装包后还要运行 `python -m playwright install`。

## 课程原则
手工测试重视需求、风险、测试设计与证据；自动化优先覆盖稳定、重复、高价值回归场景；UAT 的最终验收决定由业务授权方依据约定标准作出。
