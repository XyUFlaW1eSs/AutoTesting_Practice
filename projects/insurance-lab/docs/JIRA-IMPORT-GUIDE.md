# Jira 导入与练习工作项

## 推荐练习方式
先在个人/测试 Jira 项目中创建项目，再根据 Jira Cloud 当前导入向导导入 CSV。字段映射会受 Jira 版本、项目类型和管理员配置影响，因此先用 2–3 条样例验证映射，确认无误后再导入完整文件。

## 练习工作项建议
- Epic：投保与核保流程
- Epic：支付与保单签发
- Epic：自动化测试与 CI
- Story：作为投保操作员，我可以提交符合规则的投保申请
- Story：核保人员可以批准或拒绝待核保申请
- Story：已核保通过的申请可以模拟支付并生成保单
- Task：建立 pytest API 回归
- Task：建立 Playwright UI 回归
- Bug 演练：Pending 申请被支付、重复请求、无效保费被接受

注意：上面的 Bug 是用于测试缺陷管理流程的演练主题，不代表当前代码已实际存在这些缺陷。必须在真实执行中复现后，才能将其登记为“已发现缺陷”。
